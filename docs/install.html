Installing PolkaУстановка Polka

Five minutes, start to finish. Pick one way to install, then allow the first launch and the permissions you need. Problems are answered at the end.Пять минут от начала до конца. Выберите способ установки, затем разрешите первый запуск и нужные доступы. Ответы на частые проблемы — в конце.

Homebreweasiestпроще всего

One command in Terminal. No security prompts, and Polka keeps itself updated.Одна команда в Терминале. Без предупреждений безопасности, дальше Polka обновляется сама.

 Disk imageОбраз диска

Download Polka.dmg and drag the app to Applications, then allow the first launch once.Скачайте Polka.dmg и перетащите приложение в «Программы», затем один раз разрешите запуск.

Requirements: macOS 14 Sonoma or later, Apple silicon or Intel. The Translator needs macOS 15.Требования: macOS 14 Sonoma или новее, Apple silicon или Intel. Для переводчика нужна macOS 15.

Homebrew

Homebrew is the standard package manager for the Mac. If you already have it, step 2 is all you need.Homebrew — стандартный менеджер пакетов для Mac. Если он уже есть, достаточно шага 2.

1

Open TerminalОткройте Терминал

Press ⌘ Space, type Terminal and press Return.Нажмите ⌘ Пробел, введите Терминал и нажмите Return.

No Homebrew yet? Paste this, press Return and follow what it asks (it needs your Mac password):Homebrew ещё нет? Вставьте это, нажмите Return и следуйте подсказкам (понадобится пароль от Mac):

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

That is the official installer from brew.sh.Это официальный установщик с brew.sh.

2

Install PolkaУстановите Polka

brew tap romabmstu/polka https://github.com/romabmstu/polka && brew install --cask romabmstu/polka/polka
✓ Homebrew already allows the first launch for you — skip to First launch.Homebrew сам разрешает первый запуск — переходите к разделу «Первый запуск».

Disk imageОбраз диска

1

Download and drag to ApplicationsСкачайте и перетащите в «Программы»

Download Polka.dmg, open it and drag Polka onto the Applications folder. Then eject the disk image.Скачайте Polka.dmg, откройте его и перетащите Polka на папку «Программы». Потом извлеките образ.

2

Allow the first launchРазрешите первый запуск

Polka is not notarized by Apple yet (that needs a paid developer account), so the first time you open it macOS stops it with a message like this. That is expected — press Done.Polka пока не нотаризована Apple (для этого нужен платный аккаунт разработчика), поэтому при первом открытии macOS остановит её таким сообщением. Это нормально — нажмите «Готово».

Then allow it in one of two ways.Затем разрешите запуск одним из двух способов.

Way A — System Settings.Способ А — Системные настройки. Open › System Settings › Privacy & Security, scroll down to Security and click Open Anyway next to the line about Polka. Confirm with your password or Touch ID, then press Open Anyway once more.Откройте › Системные настройки › «Конфиденциальность и безопасность», прокрутите до раздела «Безопасность» и нажмите «Всё равно открыть» рядом со строкой про Polka. Подтвердите паролем или Touch ID и ещё раз нажмите «Всё равно открыть».

Way B — Terminal.Способ Б — Терминал. Paste this once, press Return and open Polka normally:Вставьте один раз, нажмите Return и откройте Polka как обычно:

xattr -dr com.apple.quarantine /Applications/Polka.app

It removes the “downloaded from the internet” mark that triggers the check, only for Polka. You only do this once: updates install from inside the app.Команда снимает с Polka отметку «скачано из интернета», из-за которой срабатывает проверка, — только с неё. Это нужно один раз: обновления ставятся изнутри приложения.

First launchПервый запуск

✓

Polka has no Dock icon — it lives in the notch. Point at the notch or press ⌥ ⇧ K. On a display without a notch it is a small capsule in the middle of the menu bar.У Polka нет значка в Dock — она живёт в чёлке. Наведите курсор на чёлку или нажмите ⌥ ⇧ K. На мониторе без чёлки это небольшая капсула в середине строки меню.

Want it to start with your Mac? Settings › General › Open at login. Settings open from the … button in the panel, or by launching Polka again from Applications.Чтобы она запускалась вместе с Mac: Настройки › Основные › «Открывать при входе в систему». Настройки открываются кнопкой … в панели или повторным запуском Polka из «Программ».

PermissionsРазрешения

Polka asks for each one only when you first use the feature that needs it. Everything stays on your Mac.Polka просит каждое разрешение только при первом использовании нужной функции. Всё остаётся на вашем Mac.

1

Your browser — to save tabsБраузер — чтобы сохранять вкладки

The first ⌥⇧S in each browser shows this prompt. Press Allow: Polka only reads the address and title of open tabs and opens saved groups.При первом ⌥⇧S в каждом браузере появится такой запрос. Нажмите «Разрешить»: Polka только читает адрес и заголовок открытых вкладок и открывает сохранённые группы.

2

Calendars — for your agendaКалендари — для расписания

Asked when you open the Calendar section. Polka reads events from calendars already on your Mac (Google, iCloud, Exchange) and never changes them.Запрашивается при открытии раздела «Календарь». Polka читает события из календарей, уже подключённых к Mac (Google, iCloud, Exchange), и никогда их не меняет.

3

Accessibility — for ⌥⇧T, optionalУниверсальный доступ — для ⌥⇧T, по желанию

Needed only to translate text you select in other apps. Turn Polka on in System Settings › Privacy & Security › Accessibility.Нужен только для перевода текста, выделенного в других приложениях. Включите Polka в Системных настройках › «Конфиденциальность и безопасность» › «Универсальный доступ».

Something went wrongЕсли что-то пошло не так

“Polka is damaged and can’t be opened”«Программа Polka повреждена, и её не удаётся открыть»

The app is fine — macOS shows this for downloaded apps that are not notarized. Run the command from Way B and open Polka again.С приложением всё в порядке — так macOS реагирует на скачанные ненотаризованные программы. Выполните команду из способа Б и откройте Polka снова.

Nothing happens when I point at the notchНичего не происходит при наведении на чёлку

Check that Polka is running: press ⌥⇧K. If the panel opens, see Settings › General: Open when the pointer reaches the notch and the delay. With several displays, choose where Polka appears under Show on.Проверьте, что Polka запущена: нажмите ⌥⇧K. Если панель открылась, загляните в Настройки › Основные: «Открывать, когда курсор у чёлки» и задержку. Если мониторов несколько, выберите, где показывать Polka, в пункте «Показывать на».

Tabs don’t save from my browserНе сохраняются вкладки из браузера

You probably pressed “Don’t Allow” once. Open System Settings › Privacy & Security › Automation › Polka and turn your browser on.Скорее всего, один раз было нажато «Не разрешать». Откройте Системные настройки › «Конфиденциальность и безопасность» › «Автоматизация» › Polka и включите нужный браузер.

My VPN isn’t listed or shows no statusМой VPN не виден или без статуса

Polka shows connections from System Settings › VPN, Tunnelblick configurations, and FSNT Client / Throne through its local API (enter the port and key in Polka’s settings). Connect once in your client so it registers its configuration, then reopen the panel.Polka показывает подключения из Системных настроек › VPN, конфигурации Tunnelblick и FSNT Client / Throne через его локальный API (порт и ключ вводятся в настройках Polka). Подключитесь один раз в самом клиенте, чтобы он зарегистрировал конфигурацию, и откройте панель снова.

The translator says the languages aren’t availableПереводчик пишет, что языки недоступны

Download the pair in System Settings › General › Language & Region › Translation Languages. The Translator needs macOS 15 or later.Загрузите нужную пару в Системных настройках › Основные › «Язык и регион» › «Языки перевода». Переводчику нужна macOS 15 или новее.

An update won’t installНе устанавливается обновление

Check your connection, and try with the VPN switched off if GitHub is blocked through it. You can always install the latest version over the old one with Homebrew (brew upgrade --cask romabmstu/polka/polka) or from the disk image — your tabs and settings stay.Проверьте интернет и попробуйте с выключенным VPN, если через него недоступен GitHub. Последнюю версию всегда можно поставить поверх старой через Homebrew (brew upgrade --cask romabmstu/polka/polka) или из образа диска — вкладки и настройки сохранятся.

How do I remove Polka completely?Как полностью удалить Polka?

With Homebrew: brew uninstall --zap --cask romabmstu/polka/polka. Otherwise quit Polka, move it to the Trash and delete ~/Library/Application Support/Polka.Через Homebrew: brew uninstall --zap --cask romabmstu/polka/polka. Иначе закройте Polka, перенесите её в Корзину и удалите папку ~/Library/Application Support/Polka.

Still stuck? Open an issue with your macOS version and what you see — a screenshot helps.Не получилось? Создайте issue с версией macOS и описанием того, что видите, — скриншот очень поможет.
